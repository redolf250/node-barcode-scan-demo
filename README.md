A lightweight self-checkout barcode scanner for the web.

This POC allows users to scan product barcodes using their phone camera directly from a web interface. It decodes barcodes in real-time and integrates with backend services for product lookup and cart building.

Key Highlights:
- Camera-based scanning (no hardware scanner required)
- Continuous scan flow with smart cooldown handling
- Optimized for mobile browsers
- Built with QuaggaJS for decoding and Bootstrap for UI

This project explores how web-based image processing can power retail experiences like self-checkout, inventory tracking, and smart POS systems.
